# 🧬 snMultiome Pituitary
Single-nucleus multi-omic profiling of rat pituitary across the estrus cycle, integrating transcriptomics (snRNA-seq) and chromatin accessibility (snATAC-seq) to reconstruct regulatory dynamics and gene networks.

![Workflow](.[/main/Workflow.png](https://github.com/Dalhte/snMultiome-Pituitary/blob/main/Workflow.png))

## 📚 Overview

This repository contains the **data and analysis pipelines** for the study of pituitary cell-type specific regulation:

- Multiome (RNA + ATAC) sequencing of rat pituitaries : E-MTAB-16103
- Preprocessing and multi-sample integration
- Pseudotime and regulatory time inference
- Gene regulatory network construction
- Motif enrichment and conservation analysis
- Cross-species enhancer alignments


## ⚙️ Data

- Raw and processed single-nucleus data: [EMBL-EBI ArrayExpress E-MTAB-16103](https://www.ebi.ac.uk/arrayexpress/experiments/E-MTAB-16103/)
